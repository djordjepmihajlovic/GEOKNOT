# GEOKNOT data

The folders 0_1 and 3_1 contain data files for ood and iid GEOKNOT data (biased and unbiased sampling or writhe/entanglement).
Notice, these are knot embeddings made of 100 points in \mathbb{R}^{3}.

You can run a check to ensure the topology/labels are correct within this dataset using:
``` python knot_data_check.py ```
